## 修复范围

能力落在包装 Domain Pack 的需求单检查，不增加 Agent Core 或 Enterprise 状态、Provider、依赖、工具权限或模型调用。

### 字段数量

旧叙述数字检查把“7 个必填字段”当作未在客户资料中出现的订单数值，导致合法需求单被阻断。现在只对照当前 Schema 的必填字段数，允许明确的中文/英文必填字段计数措辞；同一数字出现在订单数量等其他位置，仍须有来源。未匹配 Schema 的计数继续经过原数字来源检查，原有无来源业务数字继续阻断。复核与受限修订复用同一检查。

### 日期与交付口径

纯表示比较仍将缺少“到货/出货”口径的值保留为待核对。Worker 只有在以下证据同时成立时，才将同日的裸日期和带口径日期视为同一已确认值的表示：

- 存在匹配当前 Fact 版本、值、单位和确认引用的人工确认事件。
- 沿确认前的来源链找到原始客户文本，当前证据仍有相同引用、版本和完整原文。
- 原文的唯一交期分句匹配固定肯定句式（如“2026-11-30 到货”或“交期：2026-11-30 到货”），候选引用属于这条来源链，其他可读客户资料没有不一致的明确日期/交付口径说法；未识别的交期表述保持人工核对。
- 未遇到否定、待定、历史订单、替代选项、截断或不可读资料等不足以证明等价的情况。

该比较不重写已确认 Fact，不增加 Fact 版本、不扩大确认范围、不替代 Artifact Approval。日期不同、真正到货/出货冲突、原文换版（即使文字相同）、缺少来源链或新提议，仍保留待确认变更。已保存的旧冲突和检查点按原证据保留，不借本次修复自动解决或重放。
