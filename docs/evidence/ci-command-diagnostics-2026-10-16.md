# CI 子命令失败诊断回归

实际本机执行 policy 前置工具缺失时，`spawnSync` 没有 stdout/stderr；旧代码将两个 null 相加得到数字0，再调用 `.slice`，以二次 TypeError 掩盖原始启动错误。独立真实子进程回归在旧实现中3项有2项失败：缺失程序被格式错误覆盖，超时只报无退出状态而没有 ETIMEDOUT。非零退出与输出尾部用例原本通过。

修复仍使用标准库：缺失输出按空字符串格式化，报告 errno 和退出状态，将原始启动／超时错误保留为 Error.cause；输出仍限最后12000字符。没有添加重试、自动安装、忽略错误或放行未知状态。三个长期回归分别运行不存在的本次临时路径、合成exit7程序和受限超时程序，不依赖网络或真实模型。

该套件进入Windows必需文件清单；实际跨平台结果以当前head CI为准。本机相关59项、类型/Vite构建通过。此增量改善CI基础设施诊断，不替代业务Run/Turn/Tool事件、成本或租户观测，也不改变实验网络门禁和Windows生产禁用状态。
