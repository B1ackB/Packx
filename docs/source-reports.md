# 资料报告：文件与受限网页到版本化 Artifact

日期：2026-10-18。状态：本地纵向切片；不代表公网网站兼容性、真实用户或生产多租户验收完成。

## 可运行演示

在隔离升级仓库中使用 `.nvmrc` 指定的 Node 24.14.0。

离线两来源演示：

```sh
npm run eval:source-report
```

固定客户文件声称 90 um，固定供应商网页声称 100 um，并夹带“忽略权限、批准订单”的文本。演示经过真实 SourceReportWorkflow、Queue、SQLite 和 Artifact 存储；网页传输使用注入的离线 Fake。验收保留两份原文、来源哈希及 unverified 状态，模型调用、事实确认与审批均为 0。它不是事实裁决或真实网页质量测试。

交互工作空间演示：

```sh
npm run dev:fixture
```

打开终端给出的本地地址（现有 fixture 默认 `http://127.0.0.1:5178`），选择一个任务，上传 [source-report-customer.txt](../examples/source-report-customer.txt)，在右侧“工作区 → 资料报告”勾选该文件，填写报告名称并生成。查看来源、保存的原文和指纹，下载 JSON 报告；再次生成得到新版本，旧版本不变。该入口沿用临时数据和固定 Provider；资料报告自身不调用模型。Ctrl+C 结束 fixture 并清理临时数据，不接管原有用户工作区。

网页能力默认关闭。需要测试真实公开网页时，由 Host 在启动时显式指定精确域名：

```sh
PACKX_SOURCE_WEB_DOMAINS=example.com npm run dev:fixture
```

在同一表单添加 `https://example.com/`，每行一个链接。最多 6 项来源，其中网页最多 3 项；每项最多 128 KiB。网页读取独立于 fixture 的固定模型回复，**这条命令会实际访问配置的网站**。只允许 HTTPS/443，无登录信息、查询参数、Cookie、授权头、压缩内容或脚本执行。其他域名、私有地址或重定向越界会停止该报告；修正来源需新建版本。

本次环境尝试访问 example.com 时，其 DNS 结果被公共地址检查判为受限，返回 `web_private_address`，没有连接目标。没有放开私网、改 DNS、跳过 TLS 或放宽测试。使用 fake-IP/私网代理 DNS 的网络不在已验收范围；真实公网正向读取仍待在正常公开解析环境验收。离线 Fake、UI 请求拦截与这次被拒的公网尝试应分别理解。

## 当前产品行为

新页签与需求单、模板库、文件、资料检索、个人记忆并存。选择明确的 UTF-8 文本附件（TXT/MD/CSV/JSON）和允许的网页，Host 生成摘录与来源清单，不做模型分析。文件不会被修改，权威 Fact 和审批不会变化。

每份 `source-report.v1` 保存标题、版本、unverified 状态、来源类型、请求地址与最终地址、原始字节哈希、已保存文字哈希、读取时间、字节数、截断标记和快照引用。每份原文以 `source-snapshot.v1` 单独形成不可变 Artifact。正文最多保存 32,000 字符，报告摘录每来源最多 2,000 字符；两种截断分别显式标记。静态 HTML 只移除标签/脚本/样式并保留文字，不保证表格、布局、实体或 JavaScript 页面语义完整。

可查看已保存的原文及下载 JSON。页面以转义后的纯文本展示来源，不渲染来源中的 HTML、Markdown 图片或脚本。读取报告、下载和读取快照都重新检查任务所有权、附件当前版本/撤回状态、原始及重定向最终域名政策和 Artifact 摘要。来源撤回或政策收紧后历史仍保留用于审计，但内容入口不可用。网页不会为了“刷新可用性”自动重新联网；读取时间不是持续有效性的保证。

报告是 Enterprise 交付记录，不是 Requirement Brief，也不是已批准生产文件。当前不自动注入 Agent 上下文；可下载后作为新附件显式使用。下一切片再建立选定报告版本到 `AgentRuntimePort` 的受控读回和失效依赖，不把全部报告塞进全局历史。

## 状态、恢复与权限

`queued → running → completed | failed | cancelled`。每次派发只处理一个来源，提交来源快照和收据后释放执行片；最后单独提交报告 Artifact 和完成事件。现有 Queue 的 lease/heartbeat、取消和提交前 fence 不变。UI 从持久状态轮询显示来源进度；关闭页面不取消任务，重新打开读取同一记录。本切片未新增可重放 SSE 协议。

`source-reports.sqlite` 以 tenant/workspace/run/actor 隔离的追加事件保存 schemaVersion=1 的状态；事务内 CAS、命令摘要和去重。每任务最多 12 个报告版本，每版本最多 3 次显式尝试；重试不抹除已提交来源，不自动无限重试。只读 GET 在网络结果未落盘的窗口可能再次发生，不承诺 exactly-once。

| 情况 | 动作 |
| --- | --- |
| 命令已提交、入队前停止 | 由持久状态及确定性 jobId 补投 |
| 已提交来源收据后停止 | 重启跳过已提交来源，仅处理剩余项 |
| 来源 Artifact 已写、事件未提交 | 从同一不可变键读回并校验，补收据，不重复 GET |
| 报告 Artifact 已写、完成事件未提交 | 从冻结快照确定性重建相同内容，幂等补提交 |
| 取消或删除任务 | 先持久化状态/删除意图，再中止队列；迟到输出不得提交 |
| 429/5xx、连接/超时、可恢复存储故障 | 标为可重试；用户显式重试剩余工作，上限 3 次 |
| 来源撤回/变化、非法 URL、格式/大小、完整性问题 | 停止，保留已有快照；不靠模型或重试猜测结果 |
| 一个 scope 故障 | 独立 reconcile，保留错误并继续健康 scope |

新 SQLite 与 Artifact 均在本机受保护的业务数据目录；现有停机备份会枚举它们并检查 SQLite/WAL。没有新长期凭证或外部数据库。当前仍是本机 owner 模式，不宣称企业 RBAC；不读取任意绝对路径文件，只接受现有上传附件。升级不迁移既有业务状态。回退旧程序前取消未完成的 source-report 工作并保留新数据；旧程序没有该 handler，不能继续处理新 job。

## 网络边界

`RestrictedWebSource` 复用 Host egress 的公共地址判断；仅从静态 Host allowlist 收紧到本次用户选中的 URL。每跳重新校验域名与所有 DNS 答案，任一私网/特殊地址即拒绝；连接固定到已验证 IP，TLS 仍验证原域名。禁用连接复用、环境 Cookie/Authorization 与自动重定向，每来源总超时 15 秒、最多 3 次重定向、响应大小 128 KiB；DNS 等待也可取消。

本轮补拒文档专用 IPv4、IPv4 映射 IPv6、6to4、Teredo 等特殊目的地及非全球单播 IPv6。原生 proxy 正向 fixture 原先使用文档专用 IP，因此在新规则下失败；改为模拟公共 IP，仍经注入的 fake connect 连接本机测试上游，保持正向、域名拒绝、私网拒绝和真实 Seatbelt 断言。没有关闭原生检查或允许文档地址穿透生产规则。
