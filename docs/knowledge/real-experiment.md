# 真实全文与本地语义检索实验（2026-09-17）

> 本页保留首次真实模型基线。后续可解释查询策略的消融、完整回归和新增失败分析见 [优化实验](optimization.md)。下文“下一步”和默认路径描述是首次实验时的状态。

当前获准并实际用于索引的是 **5 篇真实研究全文、568 个片段、40 个未核验参数转录**。供应商在售型号 TDS 仍为 0，真实员工与企业私有资料仍为 0。5 篇研究不能等同于 5 款可采购产品，也没有完成 30–50 份目标。

先前的 0 是调查进度：仅核对了供应商和标准入口，未继续找到明确开放许可全文，并非所有公开资料都不能保存。这次通过 PMC 官方允许的开放数据接口逐篇核对 CC BY 4.0；另有 1 篇 CC BY-NC-ND 被排除。详见 [取得记录](../../data/knowledge/coffee-open-v1/acquisition.json)、[署名和范围](../../data/knowledge/coffee-open-v1/README.md)、[ADR-0019](../adr/0019-licensed-coffee-corpus-and-local-embedding.md)。

## 复现

Node 24.14.0，先按锁文件安装依赖；不需要模型服务账户或 API Key。

```bash
npm ci --ignore-scripts
# 仅首次需要联网：下载固定开源权重，约 135.4 MB，禁止使用付费接口
npm run knowledge:model
# 原始资料已随项目保留；只在主动复核来源时执行固定白名单获取命令
npm run knowledge:fetch
# 全部模型推理和检索在本机执行，运行中禁止网络下载模型
npm run eval:knowledge-real -- --rebuild
npm run test -- server/knowledge server/manufacturing/knowledgeApi.test.ts
```

评测输出 `.blackx-data/knowledge-real-eval/<corpusHash前16位>/latest-report.json`。不自动覆盖已保存的历史报告；更换语料会进入新的隔离目录。版本签名、固定问题、每题预期与实际命中、模型 token、耗时及硬件全部可查。不可用模型缓存会明确失败，不能静默退回 Fake 并报告语义成绩。

界面运行：`PACKX_KNOWLEDGE_MODEL=local-e5 npm run dev`。新建包装任务，在「证据 → 导入与质量状态」点击「导入 5 篇获准使用的研究全文」，等待现有队列完成。导入后地区为 `unknown`，仅表示研究资料适用地区未知；不证明 HK、CN 或 EU 订单适用。选择具体资料/研究编号，逐项点击样品、结构、厚度、原始单位、方法和条件问题。可查看原文/表格/署名、保存为任务来源；研究参数不会自动进入订单生产字段。Plan/需求单生成仍遵守现有模型配置与审批；无需付费的集成证据由专项测试提供，Fake 生成不计入真实回答质量。

## 固定题集与计分

[64 道问题与证据锚点](../../data/knowledge/coffee-open-v1/questions.v1.json)在首次排序实验前固定：28 个明确问题各有中英文版本（56 道），另有 6 道无答案生产问题和 2 道过滤问题。英文正文语料保持原文，中文查询不预先翻译。问题和证据锚点为 Agent 编写并逐条校验原文位置，**人工审核题数为 0**，不能称为工业黄金集。没有模型生成答案当作真值。

同一 Calabrese 咖啡膜研究家族（REC/ALT）均在 development；生豆研究、银皮 PLA 研究及缺答案题在 frozen。两种语言同属一个问题，64 道不能当作 64 个独立统计样本。所有文档均可检索，分组约束标签和调参用途。只进行探索性位置召回评测，没有重新训练模型或依据测试答案调阈值。

Recall@5 按指定直接证据片段计分，MRR 按首个目标位置计分；表中不包含无答案题的召回分母。检索到另一个相关介绍不能替代层厚、表行或测试条件位置。结果是对这套暂定标注的测量，不是语义支持结论的正确率。

## 三路实测

主报告：[knowledge-real-v2.json](../evidence/knowledge-real-v2.json)。相同 5 篇、568 块、64 题、K=5、串行并发 1；关键词是词项重叠，不是 BM25；向量是固定本地 E5，混合用 RRF（k=60）。三路均采用同一权限与适用性过滤。没有缓存命中、重排或付费生成。

| 路径 | Recall@5 | MRR | 原始无答案识别 | P50 / P95 ms |
| --- | ---: | ---: | ---: | ---: |
| 关键词 | 33.93% | 0.2768 | 25% | 11.82 / 14.51 |
| 真实 E5 向量 | 58.93% | 0.4670 | 25% | 25.39 / 28.92 |
| 混合 RRF | 46.43% | 0.3830 | 25% | 23.04 / 26.15 |

执行时间：2026-09-17T08:08:09.705Z。硬件：Apple M5，10 核，24 GiB，darwin 25.6.0，Node v24.14.0；模型 CPU 线程数 2。耗时包含本地 embedding、权限过滤、扫描排序和审计，不包含 HTTP、界面或生成。单次小规模串行测试，宿主机负载未隔离，不代表生产 P95。

中文 Recall@5：keyword 32.14%，vector 32.14%，hybrid 25.00%；英文：keyword 35.71%，vector 85.71%，hybrid 67.86%。

无答案识别为 2/8：只通过了型号不存在与早于出版日期的过滤，**6 道生产尺寸、报价、认证、保质期、封口温度、阀门压力问题均误召回了相关片段**。所以检索状态只是 candidates，不能直接当作已支持答案。研究参数写入限制、原值/单位校验与方法/条件追问是必要的业务边界，不是把这 6 道误召回重新算成检索成功。

出处读取与哈希完整性通过不代表引用支持结论。生成引用正确性、关键结论语义覆盖、不受支持生成结论率、通用参数抽取正确率及生成耗时/成本均保留空值。40 项数据是有限、可对照的参数转录，不是通用工业参数抽取器。

## 拆问与资料选择实验

大问题一次取 8 个片段；细分后 4 个问题各取 2 个，总片段预算同为 8。多问题顺序查询，查询次数和实际 token 明确增加，**不是同费用对比**。

| 任务 | 路径 | 大问题覆盖 | 4 个小问题覆盖 |
| --- | --- | ---: | ---: |
| REC 结构、层厚、样品和储存 | 向量 | 0% | 50% |
| 银皮 PLA 数值、氧气条件、水蒸气方法和压差 | 向量 | 0% | 25% |
| REC | 关键词 / 混合 | 0% | 0% |
| 银皮 PLA | 关键词 / 混合 | 0% | 25% |

另做“用户事先正确选中资料”的诊断：模型/资料过滤直接使用目标标签模拟用户选择，是带额外信息的 oracle 条件，不能包装成自主检索优化。逐题结果在报告 `scoped` 中；这项收益也不足以解决所有中文段落排序问题。

界面把追问分为：内容物/包装方式 → 指定资料或型号 → 具体材料层 → 数值与单位 → 方法版本 → 温湿度/压差 → 适用范围。返回值存在而方法、单位或条件缺失时分别追问，不能用储存温度替代阻隔测试温度。

## 失败案例与证据判断

- REC 原文明确列出 OTR `<0.5`，但缺少单位、方法和阻隔测试条件。系统保存不等号与空字段，拒绝据此宣称优于 STD；没有把论文储存条件填入 OTR 测试条件。
- 银皮 PLA 表 3 的列名是 OTR，单位却为 `cm3 mm/(m2·d·0.1 MPa)`。保留原始标签和复合单位，以 `OTR_as_labelled` 区分，不能和常见面积/时间 OTR 直接做数值比较。第 9 页已渲染核对。
- 生豆研究表 1 的 `L/m2 s` 是空气透过性，不能改名为 OTR。`0.075 ± 0.00 mm` 包含不确定性，不截取成一个精确标量。
- 咖啡渣 PLA 膜厚度是 `40 and 50 μm` 区间，且用于研究冷藏食品膜；不能固定为 50 μm，更不能证明 500 克零售咖啡袋可用。
- REC/ALT 论文同作者、同来源、相似表格，多处相同词项导致并列排序与证据稀释。中文版表现弱于英文版，更多拆问并不能完全补偿跨语言和大表格噪声。
- 历史 v1 曾为无 ID 摘要附加假定的网页锚点，已改为真实章节/段落位置；v2 保留修正后的语料哈希。哈希变化改变部分同分关键词结果顺序，混合分数有变化。这也说明微小语料上的单次数字不能证明稳定优化。

当前保持关键词默认；显式启用本地模型后的研究演示可选择向量路径。未将混合路径切为全局默认，也未因有模型就宣称中文检索完成。下一步先审核漏召回标签、消除同分排序影响并基于 development 做词项/表格检索实验，再使用新冻结集验证；当前冻结集已经被观察，不应反复调参后仍称独立盲测。
