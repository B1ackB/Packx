# 资料导入与用户交付模板

本功能服务包装售前需求整理。解析结果是有来源的观察；OCR、模板固定文字和字段映射均不能把业务 Fact 自动变为 verified。模板生成是本地新交付文件的保存，不发送客户，也不提交生产。

## 导入资料

1. 在会话的「＋ 图片 / 文件」上传资料；单文件不超过 10 MiB。
2. 展开附件的「导入正文 / OCR 预览」，点击「读取文档」。可以取消正在运行的解析。
3. PDF 显示逐页正文、文字层/OCR 方法、待处理页和识别警告。出现「继续下一批 OCR」时继续，直到没有待处理页。
4. 将附件随消息发送，再生成包装需求单。需求单保留原附件 SHA-256、解析器版本和页码来源。人工核对后才确认业务字段。
5. 本地文件也可从「文件浏览」打开 PDF、DOCX、XLSX，继续未完成的 OCR，再交给 Agent。

| 输入 | 实际读取范围 | 限制 |
| --- | --- | --- |
| PDF 文字层 | 最多 1,000 页和 1,000,000 个 Swift 字符，保留页码 | 不保留版面；超限明确标记 |
| 扫描/混合 PDF | macOS Vision 本机 OCR，中英文配置；逐页检测图像/表单内容，混合页保留文字层并附 OCR 补充 | 每批最多 12 个候选页，约 18 秒软预算，30 秒 CPU、512 MiB 进程树内存、60 秒硬超时；逐页图片最长边 2,400 px。OCR 不保证数值、手写、倾斜文字、表格关系及阅读顺序正确 |
| DOCX | 段落、表格行/列/段落标记、页眉页脚、脚注/尾注 | 不能推导 Word 实际分页；图片内文字、文本框及复杂嵌入对象不保证提取 |
| XLSX | 工作表、单元格坐标、保存的原始值与缓存公式结果 | 不计算公式，不应用日期/数值显示格式；不读取图表和嵌入图片文字 |
| UTF-8 TXT/MD/CSV/JSON | 分行正文 | CSV 作为文本读取，不推断字段类型 |
| 图片 | 原有模型附件及像素元数据能力 | 本次 OCR 专门覆盖 PDF；图片输入模型不等于确定性 OCR |
| DOC/XLS、加密或损坏文档 | 拒绝或显示不可解析 | 请先转换为支持格式或解除加密 |

Office 资料解析仍受 2,048 个 ZIP 条目、单条目 8 MB、总解压 32 MB 等既有限额约束。网络被 Seatbelt 禁止，不执行文档指令或宏。

文字层范围与 OCR 批次独立：51 页纯文字不会因 OCR 的批次限额截断，第 52 页扫描内容也会被识别。尚待处理的页具有 `ocr_pending` 警告及 `ocrNextPage`。原件不变时，完成的 OCR 批次保存在租户/工作区隔离、内容寻址的解析缓存中；重启后可继续。原件变动、撤回或权限变化时续读被拒绝。需求单来源读取拒绝已知仍有待识别页的资料，不将未完成 OCR 当作完整来源。

OCR 补充与文字层可能冲突；两者都保留，不静默替换权威值。置信度仅为 Vision 行候选分数，不能解释为业务准确率。低置信度与未识别文字有明确提示；渲染/OCR 异常不缓存为成功批次。

## 使用自己的通知/需求模板

1. 在自己的 Word/Excel 原件副本中，将需填充位置改为 `{{field_name}}`。占位符允许英文字母开头，之后为英文字母、数字或下划线，最长 64 个字符。允许自定义名字，例如 `{{customer_notice}}`。
2. 至少留出两个位置供「需求版本状态」和「需求版本」。可直接写 `{{delivery_status}}`、`{{version}}`。这样草稿不会在导出后丢失状态。
3. 在需求单预览展开「模板库与交付历史」，上传 DOCX/XLSX（最多 5 MiB）。界面提供可下载示例，但用户原有模板同样可用。
4. 查看识别出的填写位置及周边原文，逐项选择包装需求字段。自定义占位符必须人工映射；普通空白表格、字段标签、表单控件不会被自动识别，界面会提示准备方法。
5. 填写模板名称、说明，点击「另存为新模板」。名称、原件哈希、占位符和映射保存到本工作区模板库；每个工作区最多 100 个模板，每个模板最多 50 个不可变版本。修改映射、名称或替换原件后用「保存模板新版本」，保留旧版。替换原件会清空映射，必须重新核对。
6. 点击「预览本次订单」，核对静态文字、字段、值、缺失项和需求状态，再勾选确认并「保存新文件并下载」。保存配置不确认任何业务事实；新订单只复用原件和映射，不复制旧订单的数值或审批。
7. 在同工作区另一笔订单打开「工作区模板」，直接选择已保存配置。刷新或重启后恢复 Host 保存的选择和自定义映射，不依赖浏览器 localStorage；预览与勾选确认不会恢复，必须重新核对。
8. 「交付文件历史」列出当前任务已生成文件、格式、生成时间、需求版本、模板配置版本及当前状态。当前草稿/已批准需求可下载；失效文件显示原因并禁用下载。服务端在下载时再次检查，界面显示状态不是授权凭证。
9. 在 Word/Excel 中检查排版、分页和公式结果。相同配置、映射与输入版本重复请求返回同一文件，不覆盖原模板或旧交付物。

旧 #29 数据无需迁移：本任务已有原件可从「本任务已上传原件」选择，已有导出从 Artifact Store 自动发现。过去未保存的自定义映射无法凭空恢复，需配置并保存一次。旧文件即使没有模板库编号，也会显示为「任务原件」并按现有来源/审批重新检查。

### 明确支持的模板契约

- DOCX：正文、页眉页脚、表格内的文本占位符。支持同一段落内被 Word 拆成多个文字 run 的占位符，填充值使用第一个 run 的样式。不能跨段落/单元格，不支持循环表格行、图片替换、富文本填充或表单控件。
- XLSX：文本单元格、inline strings、shared strings 及字符串值；相同共享字符串的占位符使用同一映射。填充值是带状态/单位的文本，不宣称能作为数值参与后续计算。
- 保留模板包中的静态内容、布局、样式、合并单元格和图片；模板原本设置的固定行高或狭窄单元格仍可能截断长文本。预览是字段和正文预览，不是 Office 原版面渲染器。
- 保留同一工作表内的基本算术及 `SUM`、`MIN`、`MAX`、`COUNT`、`AVERAGE`、`ROUND`、`ABS` 公式，但 Host 从不执行。删除输出的旧公式缓存值并请求 Excel 打开时全量重算。首版拒绝跨表/外部引用、命名/共享/数组公式、条件格式、数据验证等未覆盖结构。
- 拒绝宏、外部链接、OLE/嵌入对象、主动域、外部数据连接、加密文件和无效 XML。不得用此入口执行客户模板中的指令。
- 模板最多 512 个归档条目、单条目 4 MB、总解压 20 MB、128 个占位符位置；单个填充值最多 4,096 字符，生成文件最多 5 MiB。

## 版本、权限和审计

上传、预览、生成和下载都先检查当前会话权限；服务只接收已授权 scope。任务原件与输出使用现有不可变 Artifact Content Store 的 v1 记录。工作区模板库使用本地 `template-library.sqlite`，明确以 tenant/workspace 为所有权范围，不借用固定 Run ID。配置、原件和保存审计记录在一个 SQLite 事务中写入；配置用期望版本检测并发冲突，用 actor/requestId 和请求摘要保证保存重试幂等。选择指针仅是 actor/任务级偏好，不承载业务事实或审批。配置保留原件 SHA-256、占位符、映射、版本、时间、操作者、来源任务链及 `template.configuration_saved` 事件。输出的 `requirement-template-export.v1` 记录包含 `delivery.template_generated` 审计事件名、actor、时间、模板 SHA-256、字段映射、完整需求版本快照、具体 Approval 引用、输出 SHA-256 与二进制内容。

模板库列举、选择、保存、生成和历史下载均检查来源任务权限；来源删除或权限撤回后，配置不可复用，关联输出不可下载，历史保留并标记原因。从已有配置另存或更新会保留来源链，并加入保存所在任务；单纯选择复用不会新增来源。选择库模板不会复制成可绕过来源权限的任务私有原件。跨 tenant/workspace 的模板编号不能解析，存储异常明确返回失败而非误报来源已删除。

生成前校验用户刚核对的 `reviewHash`，覆盖模板配置版本、原件、映射和重新读取的需求快照。配置更新后旧预览不能生成；历史文件仍绑定生成时的旧配置版本，单纯更新配置不会抹去旧输出或使其自动失效。原件、Fact、来源、版本或审批状态变化后，旧确认不能复用。历史/失效需求禁止生成或重新下载办公交付文件；已在用户电脑下载的旧文件无法撤回。草稿允许导出，但必须显示 DRAFT；未确认和缺失值分别标注 UNVERIFIED/MISSING。需求版本批准不等于客户模板文件或生产文件获得批准。

### 保存重试与本地验证（2026-10-16）

同一页面、同一未修改的保存操作发生响应丢失时，再点原保存按钮会沿用同一请求编号，服务端返回同一配置版本。改变原件、名称、说明、填写设置或保存方式后，视为新操作；成功保存后再次「另存」也视为新操作。该重试编号仅在当前页面内保留，刷新或关闭页面后不能宣称继续同一保存意图，应先检查模板库是否已保存。

更新复用模板时，服务端先按原固定版本检查来源与权限，再识别保存重放；同一请求不会因第一次更新已生成新版本而误报并发冲突。真正的新请求仍检查期望版本并拒绝过期更新。来源撤回或权限变化不会因重试放行。

页面保留主分支的中英文用户文案、上传控件、填写内容预览及状态说明，不显示内部哈希或 Office 文件路径。浏览器回归使用合成数据，覆盖模板目录读取、保存响应丢失后的重试、版本更新、重新预览确认、交付历史与失效下载；HTTP 回归使用本机固定 Provider 验证持久化、跨订单复用及权限边界。历史验收数字仅代表对应日期，不作为本轮通过声明。本轮本地验证通过：112 个测试文件、1035 项通过、33 项条件跳过；类型检查与构建、8 项固定离线评测通过；原生测试 42 项通过、无跳过；三种语言/屏幕配置的浏览器回归 27 项通过、无跳过或 flaky。真实本地 HTTP 回归通过，包含重启后恢复、保存更新重放、过期写入拒绝、9900 新订单数值、来源删除后复用与下载拒绝。工作流策略检查及全部候选改动文件的本地 Secret 扫描通过。汇总见 [本地验证记录](evidence/template-library-local-2026-10-16.json)。这些是本地离线与固定 Provider 证据；尚未提交或上传本切片，不声明本切片远端 CI、真实模型、客户使用效果或 Office 原生排版/重算已验收。
