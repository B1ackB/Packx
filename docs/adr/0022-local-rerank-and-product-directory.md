# ADR-0022：小规模精确检索、本地重排和业务产品目录

日期：2026-09-18。状态：已实现，业务接线验证见证据记录；工业选材效果待真实资料与人工评测。

## 背景与决定

用户要求按当前数据规模选型、对比 overlap、混合检索先取 Top 20 再 rerank，并明确要求优先建设适用于包装售前/跟单的数据库，而不是扩充论文。

业务库保留原有 SQLite 知识层、精确余弦扫描和租户过滤。试验规模为 7 篇 / 1,064 块，业务新增的是 6 条产品目录；没有新增数据库、Python 服务或 npm 包。FAISS 的 IndexFlatIP 同样可以做归一化向量的精确检索，但此规模没有实测证据表明新后端值得其部署和索引生命周期成本。多写者、共享部署或延迟/内存预算出现压力时，再按 ADR-0018 对照 PostgreSQL + pgvector；不声称已经测过 FAISS 或 pgvector 性能。

通用服务端检索仍属于 Enterprise Adapter。可选 `RerankPort` 有离线 Fake 和真实本地 ONNX Adapter；Core 没有增加行业逻辑。固定多语言 Cross Encoder，对 RRF 原始 Top 20 的问题/证据对打分，按 logit 降序稳定排序，再截为用户要求的 Top 5（最多 8）。原 RRF 分值单独保留，重排分值不视为概率或证据成立。大表格输入不静默截断：分窗口并取最大分值，完整表格仍保留；窗口偏差是已知限制。固定模型、配置和 SHA-256 见模型锁。

服务端先执行可见性、地区、日期、型号、状态过滤，再召回及重排；异步重排后再次核验可见性。模型失败或超时返回明确的 unavailable，不伪装为重排成功，不自动把原候选当结论。取消沿用信号，单次 ONNX 推理结束后检查取消。模型用量与失败未知用量分开，未完成批次为 null，不虚报零。默认不缓存，避免引入权限/版本缓存失效问题。

产品名称、供应商、咖啡形态、分类与追问属于包装 Domain Pack。新增 `packaging_find_products`，通过同一个 KnowledgeStore 读取已导入目录，只返回目录型文档，不检索论文；名称匹配和形态筛选采用可解释的确定性规则，6 条目录不需要强行向量化搜索。目录导入复用 `knowledge-import.v1`、持久队列、审计、引用读取、选择版本与需求单来源链，参数数组保持为空。目录只包括自编元数据和官方链接，不能冒充厂商全文、认证或已确认规格。公开字段和私有资料不能混淆，目录也经过现有权限和生命周期边界。

## 实验与采用范围

完整句子 overlap 0/32/64-token 对照见 [V3 实验](../knowledge/overlap-rerank.md)。保持原 500 字符软目标的切点不变，只添加同段落的完整前句，测试额外上下文的影响。overlap 0 的完整证据覆盖最佳；不推广 overlap。实验分块没有覆盖旧业务文档版本，避免破坏已有引用和参数标注。

重排相对相同 Top 20 原序提高 1024-token 证据包完整度，但相对已有表格多样化混合路径仅净增一题，且部分中文测试条件问题退步。用户要求的重排已作为本机显式可关闭的功能接入；不能称为普遍优于旧策略。论文结果只作为检索实验，不能替代供应商数据的业务验收。新下载的 2 篇只在隔离评测库，未扩入默认业务库。

## 回退、备份与退出

- 清除本机 `PACKX_KNOWLEDGE_RERANKER` 并重启，即回到原混合检索和表格多样化；向量无需重建，文档/已选引用不变。
- 删除本机模型缓存前先关闭重排。启动不联网下载；配置了缺失/损坏的权重时启动失败并要求重新准备，不能静默切模型。
- 目录在现有 UI 撤回后停止检索，影响已选需求单的引用时沿用 stale 复核。目录 90 天复核期限是 Packx 的维护策略，不宣称供应商原文失效日期。
- 没有 Schema 迁移。SQLite WAL 和原始 manifest 快照沿用既有备份方案；原始 XML/PDF 与模型锁独立保留。索引可由快照重建。
- 实验将 source hash 固定。生产适配器继续演化后，旧实现保存为 `data/knowledge/chunking-v*/source-snapshots/store.ts.txt`；重放命令在临时源码目录使用快照，不覆盖当前代码或历史报告。

## 替代方案

保留只有关键词的产品目录、把全部论文作为业务知识、引入托管重排 API、立即增加 FAISS/pgvector、把长文用固定字符 overlap 切开，均已考虑。当前采用目录结构化入口加可选本地重排，不引入付费服务。需要进一步优化时必须先增加符合业务分布、经过人工核验的供应商资料和问题，不能继续靠论文数量或模型生成答案证明效果。
