# ADR-0041：只读计划的冻结输入依赖记录

后续状态：历史工具/文件来源复核已在 [ADR-0042](0042-completed-tool-source-review.md) 本地切片接入；本记录保留此前阶段的范围、测试及当时未提交状态。本次用户另行授权全部必要变更验证后本地提交，仍不对远端发布。

日期：2026-10-20。状态：本地实现与验收；未发布。远端基线：PR #55 合并后的 main `42ff79c8a8e680ab436c170ca2d6f1aaab4e7b1d`。在尚未提交的 ADR-0040 结果过期闭环上增量实现；不提交、推送、创建 PR、部署或调用付费模型。

## 背景与落点

ADR-0040 用冻结上下文识别原有已确认 Fact 和 Artifact，避免导入产生的新草稿反向使来源过期。但规划时已有的 unverified/suggested/rejected Fact 同样进入 worker 上下文，完成后却未持续核对。六个基线回归证实：其值、版本、确认状态、来源引用、来源可用性或存在性变化，结果仍显示 completed。

本阶段只补 Enterprise Layer 的冻结输入依赖，复用 Plan SQLite 事件、完成态检查、stale 和重新确认入口。不修改 Agent Core、Runtime Port、Provider、权限或并发调度，不创建通用依赖图、额外数据库或后台 watcher。

## 决定

1. Host 为新产生的 `readConcurrency=2` 计划，在 `plan.proposed` 同一事务中记录 `inputDependencies`，早于用户确认。仅识别 Host 的 `task-context.v1`。模型的 Plan JSON 没有此字段，也不能选择依赖、提供摘要或提升输入状态。
2. `plan-input-dependencies.v1` 记录当时全部 Fact 的 key/version/SHA-256、原有 Artifact 的 artifactId/version/SHA-256，以及其余任务输入投影的摘要。记录摘要覆盖完整输入记录，包含候选状态、值、来源和可用性；摘要不是来源权威或签名。原始内容继续位于既有冻结 context，不在清单中重复。整个清单至多 128 项，标识至多 128 字符，版本必须是正安全整数，摘要必须是 64 字符小写十六进制；拒绝重复身份、未知清单字段和无效数据。
3. 完成态读取先核对清单与原冻结 context，再按冻结身份集合核对当前记录。记录消失、版本/状态/内容/来源变化均过期，包括人工确认原有候选。仅记录顺序变化不使结果失效。其他输入（scope、报告选择、附件、知识、对话、检查点、个人记忆及未知新增字段）继续精确比较摘要；对话 revision 另行比较。阶段进度、已完成阶段、pendingChanges、审批和确认待办投影不作为上游。
4. 之后新增的 Fact 或 Artifact 不会自动进入旧计划清单，其后续确认也不会成为旧依赖。下一次显式生成/重新规划才捕获当时的输入集合，并要求新确认。原有输入被确认则会改变该输入记录，须重新规划；这不阻止人确认 Fact，只阻止继续把旧结果视为当前可用结果。
5. 继续复用 `plan.results_stale`、确定性版本命令键与 CAS。重复读取、重启和恢复旧输入不复活旧结果，不增加调用、尝试、失败或费用。原始清单、结果和确认保留作审计历史。导入复核同一入口；界面可在确认前展开冻结版本，明确包含未确认内容且记录版本不等于验证。
6. 旧计划没有清单时不补造或静默改写历史，保持 ADR-0040 的已确认 Fact/原 Artifact 校验；旧文本 context 保留整段比较，旧串行/含写入图保持原行为。新 Host 的标准 task-context.v1 只读图必须在提案时成功记录清单，失败则停止并显示原因。

## 替代方案与限制

直接把所有当前 Fact 都当作旧依赖会重现导入自失效；只改过滤条件不能向用户展示冻结集合，也不能区分旧计划语义。通用失效总线、节点租约、依赖推断和新持久化层超出本阶段，均不采用。

清单代表共享冻结任务输入，可能保守覆盖 worker 未实际使用的原有候选，不推断模型语义依赖。任务快照外的历史 `file_read` / `context_read` 输出、工具压缩依赖和完成后的文件撤权持续复核尚未接入该清单；现有 Runtime 仅在执行/恢复边界校验这些来源。下一阶段需复用其异步来源校验与不可变读回证据，再扩大完成态校验，不能另写路径检查绕过文件权限。

并发仍至多两个只读节点、最多四节点静态 DAG，单图 lease 与批次汇合；不开放跨图并发、写入或任意代码。调用/Token 限制不是精确费用上限；固定 Eval 不证明真实模型收益。

## 迁移、回退与退出条件

清单是现有 Plan 事件快照的可选字段，无数据库结构迁移，不回填旧版本。升级前仍应停止任务并一致备份 Plan、Queue、Session/Trace、来源与 Artifact。遵守 ADR-0040 的 stale 兼容边界，不与旧二进制混跑，不删除事件或确认以伪造回退兼容。新增资源类型、精确工具读取依赖或超过当前输入规模时另行定义版本和完成证据。
