# ADR-0012：真实本地文件与全写入审批

> 后续修订：[ADR-0025](0025-evidence-bound-recovery-and-explicit-degradation.md) 增加有证据的文件结果对账，以及通过新审批恢复历史版本的补偿操作。

> 历史记录：目录预授权交互已由 [ADR-0013](../adr/0013-just-in-time-file-approval.md) 替代。当前使用 Agent 发起的单次文件操作审批。

- 状态：Accepted；2026-09-05。
- 来源：用户明确要求 Agent 操作电脑上的文件，读不必逐次审批，写和删必须由用户审批。
- 替代 ADR-0011 的“仅限会话文件区”和“首次新建自动批准”策略。未改动 Core 或 Domain 边界。

## 决定

复用文件 Tool、审批、审计、幂等账本和历史 Artifact，在 Enterprise Host Adapter 增加 `LocalFileAccess`。界面允许当前用户输入真实本地目录并授权读取。授权绑定 tenant/workspace/conversation，记录规范绝对路径、目录设备/inode、授权人和时间；撤销记录保留，并取消该授权下尚未执行的审批。模型没有创建目录授权的工具。

`file_list({path?})` 无参数返回授权目录和历史文件，指定绝对目录则枚举磁盘条目；`file_read({path})` 读取 UTF-8 文件并返回 `absolutePath/sha256/content/size`；`file_write({path,expectedSha256,content})` 和 `file_delete({path,expectedSha256})` 都需逐次人工审批。首次新建 `expectedSha256=null`，修改/删除必须使用读到的摘要。原始附件、内部审批/审计/数据库及已批准交付目录保持受保护。

相对路径接口保留旧会话文件和历史兼容，仍使用 `expectedVersion`，但新建也需审批。旧文件从来都是 Host 磁盘上的持久文件，现返回真实 `storagePath`；这个路径代表不可变快照，而非可编辑原文件。用户可让 Agent 读取旧文件，再通过审批写入本地授权目录，无需手工复制全文。

## 写入和恢复

审批绑定绝对路径、当前内容哈希、文件身份、拟写入内容、授权 ID、用户和幂等键。执行前再次验证会话、授权、目录真实身份、原文件哈希及文件身份。原文件在审批期间变化时拒绝执行。路径跳转、目录/最终文件符号链接、硬链接、设备、隐藏凭据路径及已配置内部数据目录不可访问。

执行前先保存原文件内容的不可变备份及 `executing` 意图记录，再操作磁盘原路径。新建通过临时文件硬链接实现原子“不覆盖”；修改写入同目录临时文件后替换原文件；删除从原路径移除文件。成功后提交结果与历史版本。文件内容和索引使用 fsync；旧文件权限位在修改时沿用。所有原文件变更均需审批，不把目录授权当作写入授权。

文件备份是可下载的历史版本；恢复到原路径属于新的写入，仍需审批。已完成操作重复投递只返回原结果，不再次改写。如果进程在外部文件变更与账本完成之间崩溃，保留 `executing/unknown`，禁止盲目重试，由用户核对磁盘与备份后决定恢复。审批等待继续遵守 Turn 两分钟预算及取消信号。

## 限制与后续门槛

这是单个本地 Host 的受控文本文件工具，不是多进程事务文件系统。支持不超过 128 KiB 的 UTF-8 普通文件，目录列表最多返回 200 项。二进制 PDF/Word/图片编辑、目录创建/递归删除及任意 Shell 不在本切片内。文本应使用相应文本格式；生产文档仍需专用工具与校验。

在文件检查和最终操作之间，不能承诺与不合作的外部进程实现原子 compare-and-swap；目录身份和源文件身份在操作前复核，变更前有备份。不要让多个 Host 共享同一索引；恶意同权限本地进程不在此 Adapter 的 OS 隔离保证内。若需要多写入者、二进制编辑、保留 ACL/xattr 或完整崩溃自动恢复，应采用对应文件平台能力、事务存储及专用原生 Adapter，并补故障注入回归。

目录授权由用户选择，不预先扫描或修改用户数据。无数据迁移和自动授权；重启 Host 后在界面添加目录即可使用。验收见 [真实本地文件回归](../evidence/local-file-access-2026-09-05.md)。
