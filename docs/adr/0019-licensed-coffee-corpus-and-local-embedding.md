# ADR-0019：开放许可研究语料与本地语义检索实验

- 日期：2026-09-17
- 状态：已实施本地实验；供应商资料与企业验收未完成
- 延续：ADR-0018，不修改 Agent Core、业务数据库或审批状态机

## 背景与决定

首次来源调查只登记供应商、标准与法规入口，未找到可确认全文保存/索引许可的具体资料，因此当时真实入库数为 0。继续调查发现 PMC 开放数据集中的 CC BY 4.0 咖啡包装研究论文，可以依法保留署名、许可及修改说明后使用。不能因“公开可读”就入库，也不能因供应商版权未确认就停止寻找开放许可来源。

1. 固定 5 篇论文的 XML/PDF/元数据快照，逐篇校验许可、身份、撤回状态及发布者 MD5、本地 SHA-256；排除一篇 CC BY-NC-ND 资料。原始全文保存在 `data/knowledge/coffee-open-v1`，派生知识快照与索引沿用原有层次。
2. 通过 PMC 官方允许的 S3 HTTPS 数据集接口获取，禁止网站爬取。采集器是只含 6 个固定条目、固定协议/域名/路径、无重定向、10 MiB/30 秒限制的操作员命令，不向 Agent 开放。此机器使用 198.18/15 DNS 代理，既有运行时下载器继续拒绝该地址；没有放宽 SSRF 规则。
3. 新增 JATS Adapter，保留段落、章节锚点、表格多层表头、行、复合单位及脚注。正文与摘要分段，表格逐行索引；引用文献、图像和补充文件不进入检索。原始全文始终保留。没有 PDF 页映射时仅报章节/段落/表位置，不猜页码。
4. 新增本地 ONNX Embedding Adapter：`@huggingface/transformers@4.3.0`、固定 multilingual-e5-small 提交、q8、384 维、均值池化、L2 归一化、CPU 两线程、query/passage 前缀。长段超过 480 tokens 时按空白分窗分别编码后均值归一化，不静默截断，记录真实 token 与 forward passes。模型空间签名包含这些配置。
5. 显式 `knowledge:model` 下载权重；普通启动与检索禁止模型网络加载并校验模型文件哈希。没有付费 API、LLM Judge、重排或在线查询改写。
6. 研究材料以 `study:PMCID` 标识，`research_report` 与供应商型号区分。40 个来源绑定的参数转录全部 unverified。研究样品参数及同一块中含多个同名层参数不能由 Worker 或一键按钮写成订单生产字段；可保留为任务来源并向供应商追问。
7. 首次模型调用前固定 64 道问题，相关论文置于同一家族分组。标签为 Agent 对照原文、待人审；检索位置召回与回答正确性分开报告。再做等片段预算的拆问实验和“正确选择资料”的附加信息诊断。

## 替代方案、成本与限制

继续仅用合成数据无法回答真实语义检索是否有效。直接采购供应商数据/使用付费模型没有授权。PMC 研究数据有明确复用许可，适合验证工程，但与在售咖啡袋 TDS 存在明确覆盖差距，不能据此宣称 30–50 份目标或主流市场覆盖。

ONNX 本地 CPU 路径新增约 135.4 MB 模型/分词器缓存以及 npm 传递依赖，已固定来源、版本及许可证；相比 Ollama 路径无需安装本机服务。新增依赖及哈希见 `docs/dependencies.md` 和模型锁文件。运行成本包括本机计算，不能把“无 API 账单”写为零基础设施成本。

SQLite 仍是本地单 Host 实验实现。没有 ANN、共享多租户部署或 pgvector 实库成绩。此次 568 块实验规模也不足以支持引入新数据库。

## 迁移、回退与退出条件

模型空间变化后必须从不可变清单重建索引；旧向量不能参与新空间检索。关闭 `PACKX_KNOWLEDGE_MODEL=local-e5` 后如需哈希基线，也应重建索引。向量适配不改变事实或审批状态。备份除业务知识快照外还须保留对应原始 XML/PDF、acquisition.json、模型锁、解析器/标签版本；权重可以按固定提交另行恢复。

JATS 扩展在既有导入 Schema 中增加可选章节定位和研究权威类型，数据布局仍为 v1；旧程序不能保证解释新研究记录，回退使用升级前完整备份，不能让旧代码直接处理新语料。

研究版本或许可变化后先停止检索/撤回来源，再复核受影响任务；更新元数据后重新点击研究导入会撤回登记表排除的研究文档，沿用 stale/Approval 失效链。此机制需操作员触发，不宣称持续在线监控。只在获得供应商许可、独立人工标签和实际负载后再扩展资料规模、检索优化或 PG 部署。
