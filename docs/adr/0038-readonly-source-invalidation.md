# ADR-0038：报告变更主动失效已确认的只读计划

日期：2026-10-19。状态：Accepted，本地实现与验收完成；完整检查的首次失败和最终复验结果均保留。基线：main `866379759e2113fd7948cf671e7c17a48f995660`（PR #54）。该切片最初未获提交授权；用户后续授权补齐缺口、通过测试后本地提交，见 [ADR-0039](0039-readonly-source-recovery-and-report-dependencies.md)。未授权推送、PR 或部署。

## 背景与完成证据

ADR-0037 已有两个只读节点的隔离、预算预留、取消和结果提交 fence。检查真实代码发现 `dispatch` 读取最新输入却未与已确认快照比较，报告变更 API 也未主动通知计划；旧撤回 fixture 随后放行了挂起模型请求。它证明结果不会提交，却没有证明等待中的批次会被及时停止。新增回归先在基线上复现：两个 Adapter 挂起时，撤回后 reconcile 仍为 running。

本阶段属于 Enterprise Layer：在 Provider 尚未返回时使旧计划失效，释放现有调度器，保存历史结果；不增加调度框架或 Agent Core 能力。

## 决定

1. 报告变更命令先完成自己的持久化，再调用同 scope 的 `AgentPlanWorkflow.dispatch`。新建报告而不改变所选绑定时不会停止计划；重新选择同一版本仍按既有 selectionRevision 合同失效。
2. 派发/对账入口只对已携带 `readConcurrency=2` 且 active 的计划比较 input revision/context。确认变化后先用确定性 `sources-changed:version:generation` 命令持久化 `plan.sources_changed`，沿用非自动重试失败状态、现有失败上限和节点 interrupted 投影；随后复用整图取消路径，包含非规范/旧重复 job。
3. Scheduler 的现有 AbortController 传播到两个 Runtime，abortable 使不可合作 Adapter 不再阻塞调度；它不证明远端 Provider 已停止计费或回滚。已预留消耗不退还。迟到响应继续受原 lease/版本/代次/来源 fence 约束，不添加 child 或启动汇总。
4. 完成收据和原批准记录留作历史核对，失败不可直接 resume。用户结合新来源提出新版本，重新确认后才执行；不把旧结果升级为已验证 Fact，也不跨版本继承审批。
5. 报告存储、计划事件和队列之间不引入跨库事务或通知总线。报告已保存但计划未失效时，启动/下次 reconcile 比较快照；计划已失效但取消失败时，重复 dispatch 走既有清理路径。重复命令不新增失效事件或执行消耗。API 返回已分类的来源或计划错误；遇到错误应使用原 requestId 重放或按本地维护流程恢复，不能把来源保存视作已回滚。
6. 只有成功读回且实际不同的快照构成失效证据。context store 不可用继续报告原错误，不能伪装成撤回、取消其他 scope 或吞掉故障。

## 替代方案与影响

继续等 Provider 返回或 60 秒超时会保留陈旧运行状态，并阻塞后续调度；新增全局 watcher/总线则扩大生命周期和资源面。本阶段在现有报告 API、派发入口及取消链路完成闭环，不加依赖、配置、工具、预算或权限。确认前的计划、旧串行图和包含写工具的图保持既有行为。

## 迁移、回退和退出条件

无新状态字段或数据库迁移，追加事件沿用原完整状态 Schema。升级按现有停机及一致备份流程进行。回退时停止/排空只读计划并保留来源、计划事件、队列、Session/Trace；撤回此代码只会恢复原提交前复核与超时行为，不得复活已失败计划或删除失效事件。若报告变更请求因存储故障未完成通知，先修复存储并对账，不能通过放宽来源检查继续。

## 验收与剩余边界

见[本地验收和演示](../evidence/readonly-source-invalidation-2026-10-19.md)。覆盖挂起请求、保留成功兄弟、重复 job、幂等、失效落盘后取消失败、上下文存储故障、作用域隔离、重新规划和迟到响应；真实 Host HTTP 使用本机固定 Provider。

主动通知仅覆盖本 Host 报告变更 API，其他来源或权限变更仍依赖原 Runtime/提交前复核或下次对账。没有后台来源轮询、跨业务 Artifact/Approval stale 传播、节点独立租约、跨图并发、公平调度、并发写文件或任意代码执行。预算耗尽后零调用完成 Trace 的恢复入口仍受现有 resume 预算门槛约束，后续独立补齐。网页默认关闭，公网正向读取、真实模型质量/费用、真实用户收益未验证。
