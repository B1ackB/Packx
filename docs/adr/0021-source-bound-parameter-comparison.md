# ADR-0021：按来源参数引用执行比对

- 日期：2026-09-17
- 状态：已实施，本地规则和业务回归通过；工业正确性待专家审核
- 延续：ADR-0018、0019、0020；不修改 Agent Core、业务存储或 Approval 状态机

## 背景

召回相关文档后，旧实现会批量配对同名参数。方法、范围和条件只要字符串相同就可能放行，因此 `unknown`、`N/A` 或空白也可能被当作有效依据；缺少逐项阻隔条件时也没有独立检查。同研究文档中不同样品的差值还可能被误认为版本冲突。

在改写比较规则前固定 40 个用例并保存旧结果，发现 17 次错误放行。32 个用例是项目自编的软件规则契约，8 个是从既有论文取出的待人审参数对；不将其标成工业黄金答案。

## 决定与分层

1. Enterprise `EvidenceParameter` 增加可选、通用的 `testConditions: {name,value,unit}[]`，最多 8 项，拒绝重复名称、超长或额外属性。导入要求每个原始值和非空单位出现在同一来源块。该校验只证明字符串出现，不证明字段对应关系或科学正确性。
2. 通用 Knowledge Store 按 `evidenceId + parameterIndex` 读取恰好两条参数。权限在 SQL 中、版本/地区/日期/授权有效性在返回前执行；精确引用直接按块主键取数，避免为读一个引用加载整库。记录关联 ID、引用、过滤条件、消费规则版本、索引版本和耗时，不在审计重复正文或参数值。
3. 包装 Domain 维护可比较指标/单位、未知值规则和逐项条件要求。厚度换算继续使用确定性逻辑；区间、不等号和误差原值不截取成标量。价格、证书、保质期和含义未核实的 `OTR_as_labelled` 不通过通用数值比较器。
4. 对 OTR，自动计算至少要求显式温度、相对湿度、压差和气体；WVTR/WVP 要求温度和两侧湿度；空气透过性要求温度、相对湿度、压差。条件值/单位必须逐项相同，数值条件必须为明确标量，所有额外条件也必须相同。不将自由文本相同当成条件完整。
5. 这些是 Packx 的保守放行规则，**不是某个 ASTM/ISO 标准的合规判定，也不是对所有影响因素的完整物理建模**。未知单位、单位形式不同、未支持的测量类型或未转录的条件均要求人工复核。温度、压力等不做推测换算；必要扩展先补固定样本与规则测试。
6. 新增 Domain Tool `packaging_compare_evidence` 和同实现的 `/knowledge/compare` 接口。输入只能引用已入库的来源参数，不能传入替代数字、单位、租户或“已验证”状态。返回两侧厂商、型号/样品、版本、位置、原值、归一化值、字段缺口和规则版本，最长 24,000 字符；超过返回限额则明确报错。
7. UI 改为显式选择两条参数，报告左减右的数值差或阻断原因。Agent/Plan/需求单可使用受控工具。比较始终 `unverified`、`conclusionAllowed=false`；数值可比不表示厂商优劣、订单适用性或事实获批。重要交付仍由既有选择快照、Fact、Artifact 和 Approval 保存来源；一次只读比较预览不会修改它们。
8. 不同样品不再自动标作同一型号记录冲突；来源权威类型分别保留。辅助冲突扫描限制为 64 组并明确提示截断，用户可以指定任意合法参数对继续核对。新读取流程不引入缓存。

## 替代方案与代价

直接让模型阅读数值并比较，会混淆材料层、单位及条件，也难以复现。只做文本归一化无法证明测试条件完整。引入图谱或新的抽取模型超出当前闭环，需要更多授权数据和独立评测。因此采用既有解析结果、引用边界和少量确定性规则。

保守规则会阻断部分真实但条件尚未结构化的参数。当前 8 个研究来源对均被阻断，缺少获准供应商 TDS 的真实正例。该限制优于猜测补齐，但不能宣传为高工业准确率。研究参数继续不能自动成为订单生产字段。

## 验证与演进

固定协议用例、错误放行/错误阻断计数、真实本地 E5 的 64 题排序回归、Tool/ContextEngine/需求单、HTTP 权限/撤回路径分别记录；浏览器视觉验收因电脑锁定未完成。实验见 [比对报告](../knowledge/comparison.md)。无新依赖、付费调用或数据库迁移。

添加条件字段会改变导入清单内容哈希，形成新文档版本；旧版本和旧选择不会被原地更新。默认 5 篇研究的原文及清单未补造条件，旧语料、索引与标签保持原样。

字段为可选，既有无条件清单仍可读取，但比较时会报告缺口。若撤销本功能，应停用比对 Tool/入口并保留原文阅读；**不能把有已知错误的旧比较器重新用于业务放行**。旧算法只在离线评测中保存以复现前后差异。原文/知识库备份与恢复方案继续沿用 ADR-0018；条件更新、权限撤回及已有交付物失效规则不变。
