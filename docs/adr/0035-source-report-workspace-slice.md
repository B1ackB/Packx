# ADR-0035：工作空间来源报告采用受限读取与确定性 Artifact

日期：2026-10-18。状态：Accepted，已实现；公网正向读取尚未验收。

发布更新（2026-10-19）：本批已获独立推送与条件合并授权，纳入 [PR #53](https://github.com/B1ackB/Packx/pull/53)；历史授权描述按原日期保留，现行验证/迁移边界见[发布记录](../evidence/workspace-agent-publication-2026-10-19.md)。

## 背景

ADR-0034 交付了串行 DAG，但仍没有独立来源快照到通用交付物的工作空间路径。产品负责人要求继续贯通文件、受限网页、版本化报告并完善权限/恢复，不授权付费 API、持续凭证、升级 push/部署或系统安全更改。

## 决定

- 用 Enterprise 的 `SourceReportWorkflow` 复用现有 Queue、ArtifactContentStore、附件授权和本机身份。Core、ReAct、需求单和模板库不重写。
- 新建工作空间“资料报告”页签；用户显式选择 UTF-8 附件与静态 Host 域名 allowlist 内网页。Host 产出确定性的摘录和来源清单，永远保持 unverified，不用模型作无证据的比较/核实。
- SQLite 追加状态事件及版本合同、CAS/命令去重、每来源检查点、不可变原文和报告 Artifact、取消/lease fence、最多三次显式重试；恢复不重复已持久化快照。
- HTTPS 网页使用 Node 标准库，逐跳验证域名及公共 DNS、固定已验证地址、正常 TLS 验证、内容/时间/大小上限，无凭证和脚本。默认关闭；不因当前网络的私网/fake-IP 解析而放宽限制。
- 读回/下载重新校验所有权、附件撤回/版本、最终域名政策与 Artifact 摘要。UI 只显示转义文字；历史不原地覆盖。
- 不引入依赖或外部服务，不增 Agent 数量。下一切片再把用户选定的报告版本作为显式任务上下文依赖接入 worker。

## 替代与取舍

直接把网页交给模型不能保障 SSRF、事实或恢复；任意 URL fetch 和无边界 Shell 不采用。为此引入浏览器服务、分布式图引擎或另一个 Agent 框架缺少证据；当前只做文本附件和静态网页。现有原生文档工具继续在原流程使用，不为本切片复制造成新不确定性。

代价是当前报告不会自动进行语义归纳、不能处理动态/登录网页，且需要 Host 配置域名。源码/Artifact 有哈希不代表内容事实正确；DNS 私网代理环境无法完成正向公网验收，明确保留限制。

## 验证、迁移与退出

实现说明、演示、恢复矩阵见 [资料报告](../source-reports.md)，实际结果见 [阶段证据](../evidence/source-report-slice-2026-10-18.md)。离线 Fake 与真实网页验证分开；没有真实用户收益结论。

新数据库放在原业务数据根，不迁移旧状态；关闭时释放，原停机备份策略覆盖 SQLite/WAL 和 Artifact。回退前取消新 handler 的未完成 job、保留新数据。不删除旧需求单或模板成果。若真实任务显示来源收集无价值，隐藏新入口并保留历史读取；并发、任意代码和模型比较仍按独立 Gate 引入。
