# ADR-0028：复核输出预算与当前事实回答校验

- 日期：2026-09-29
- 状态：接受工程边界；16384 候选已完成限定在线对照，未达采用门槛
- 分层：Host / Runtime Adapter / 包装 Domain；不修改 Agent Core Loop

## 背景

9 月 26 日实测包含复核 `max_tokens` 截断、当前事实已进入请求但回答仍使用旧数量，以及字段等价表示与评分不一致。失败用量保全已实现；关闭推理、低推理和精简指令的旧实验均未达到采用门槛，保持原结论。

## 决定

1. Runtime 以不可自动重试的 `output_limit` 返回收到的截断终态，区别于无效 JSON 和拒绝。复核报告保留该分类、原草稿及禁止审批状态，恢复不重复购买调用；现有遥测继续保存失败用量。
2. `RuntimeTurnRequest.limits.maxOutputTokens` 可显式限定本阶段输出预算，不得超过操作者配置的模型上限。计数、上下文预留和生成使用同一预算。包装 Host 可配置 `PACKX_REVIEW_MAX_OUTPUT_TOKENS`，只用于独立复核及其有界修订；未配置沿用原行为。预算进入 review-input 和调用意图，因此旧执行不能在恢复时悄悄改预算。
3. Host 可为结构化回答提供最多 32 个顶层原始值 `expectedOutputFields`。Adapter 在保存最终回复、发出完成结果之前精确验证这些值，缺失、类型不同和过时值均拒绝。已声明合同的回答不流出未经验证的部分文字；只记录失败字段名，不复制权威值进普通错误日志。模型不能修改校验值，失败不自动修复或覆盖输出。
4. 输出合同摘要保存在 Trace。同一 Session 和幂等键不能切换预算或校验字段；已完成回复重放也校验合同。现有当前上下文绑定在结果接受前再次检查。无新增字段的旧调用保持兼容。
5. 包装 Domain 统一严格表示比较：十进制表示、已列明计数单位、尺寸符号及单位位置。比较只影响候选相等判断，不重写已确认值、版本或来源。到货/出货、内/外尺寸、轴序、单位换算及额外业务限定不能被丢弃。未知表述保留人工复核。
6. 新评分入口 `requirement-automatic.v2` 使用该字段规则，分别输出明确冲突、表示等价和待复核原因；来源、确认、版本、审批和 Artifact 检查继续独立。旧 v1 规则、素材与历史分数不变。连续上下文新计划标为 `continuous-context.v2`，带当前事实结果校验，不再把旧值回答保存为成功回复。

## 替代方案与限制

不通过自动重试、放宽审批、采用已失败的推理配置或删除输入证据处理截断。预算增大只是可验证的候选，可能增加成本、延迟，仍可能截断；需另冻同输入同模型的对照，并披露预算差异。本次不改变运行中的私有配置。

顶层精确字段校验不是通用 JSON Schema 引擎，也不判断自由叙述语义。只有 Host 声明的字段受到保护；调用方必须从当前权威状态构建它们，并维护 taskContext 版本绑定。现有需求单仍从 Host Facts 构建交付；普通自由文本聊天不因本改动获得全面事实正确性保证。

## 验证、迁移与退出

离线契约覆盖预算边界、错误分类、未完整 Tool 禁止执行、失败用量、暂停/重放、当前事实变化、关键输出拒绝、租户隔离和复核恢复。历史旧数量响应进行离线结果接收校验回放，不能称为新的模型任务成功。

新增 Trace 字段和请求字段可选，无破坏性存储迁移。旧复核输入仍不可变；改变预算后必须开始新执行。回退时保留新 Trace/Artifact/评测记录，停用新调用配置；不能把已拒绝的回答补写为成功。更广泛嵌套结果校验只有在出现具体业务需要时另行设计。

## 后续验证

2026-09-29 经独立 2 美元授权完成 60 次只读生成。16384 组截断为 1/30，8192 组为 4/30；候选控制检查 20/22、有效输出动作检查 25/28，未达预设门槛，不采用新默认值。详见[在线证据](../evidence/review-output-budget-2026-09-29.md)。此结果不改变已接受的预算边界与输出校验机制。
