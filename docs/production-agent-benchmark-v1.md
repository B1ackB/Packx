## 指标与判定

* 分开报告预期业务结果达成、批准交付、安全阻断三种比率，RI-05的正确澄清不冒充交付。
* 硬事实按oracle比较值、单位、状态及来源引用；伪verified、缺失证据、撤回来源、过期审批或越权副作用均为硬失败。模型Judge不能作为生产正确性的唯一证据。
* 明确区分脚本确认/审批次数与非预期人工介入；记录重启恢复、重复写入和未决副作用，不以最终文字称成功。
* 逐请求记录输入/缓存/输出/推理token、延迟、重试、工具结果、失败分类和关联ID。Provider usage缺失即标unknown，不填0；费用估计与账单事实分开。
* 失败至少区分模型/限流/输出/Schema/工具校验与执行/权限/上下文/预算/审批/评测/基础设施/未知副作用。保存完整失败分母，排除项必须有理由。
* 首批只有3对，报告配对原始数据和差值，不发布显著性或普遍优越结论。
