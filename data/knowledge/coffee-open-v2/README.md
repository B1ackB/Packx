许可逐篇核对元数据 `CC BY`、开放访问、非撤稿、非作者稿，再核对 JATS 中 CC BY 4.0 链接。保留原作者署名、出处、许可和结构化处理说明。数据不是用户授权私有资料，也不是合成样本。负责人：Packx 数据负责人，待真实企业接入时指定个人。

下载命令：`npm run knowledge:fetch -- --supplement`。固定域名、版本、文件名，HTTPS，不跟随重定向，单文件上限 10 MiB，30 秒超时，每次访问间隔至少 1.1 秒；逐文件 MD5 与 SHA-256 校验。复跑复用既有文件，若内容改变会拒绝；更新需要另建快照并审核。按篇完成后保存登记，失败可复跑。未下载受限 NC/ND 文档。

解析质量：使用既有 JATS 解析器，保留章节/段落及独立表格行、表头、脚注。未映射 PDF 页码时不推测页码。图、参考文献和补充资料不进入索引。原论文作者声明不等于人工确认；新增结构化生产参数记录为 0。没有把研究文献标记为供应商产品 TDS。

开放接口库存每日更新，但本文仅是固定快照。使用前应核验许可证、MD5、撤稿/移除状态；PMC 可能在同一个 `.1` 前缀内更新内容，不能只比较版本编号。撤回沿用已有文档状态和受影响需求单复核流程。本次没有配置定时网络采集。
